Dad Builds AI Studio User Data Deletion Instructions

Dad Builds AI Studio가 관리하는 사용자 데이터의 삭제를 요청하려면 아래 절차를 이용해주세요.

1. 삭제 요청 방법

이메일: kpl814@naver.com

제목: [Dad Builds AI Studio 데이터 삭제 요청]

2. 요청에 포함할 최소 정보

  • 삭제 대상 Instagram 또는 Threads 사용자 이름
  • 서비스에 연결했던 계정을 식별할 수 있는 최소한의 연결 정보
  • 어떤 데이터를 삭제해 달라는 것인지 명확한 요청

요청자와 대상 계정의 관련성을 확인하기 위해 추가적인 최소 정보가 필요할 수 있습니다.

3. 보내면 안 되는 정보

비밀번호, 액세스 토큰, App Secret, 인증 코드 또는 기타 로그인 비밀정보를 이메일로 보내지 마세요. Dad Builds AI Studio는 삭제 요청 처리를 위해 이러한 정보를 요구하지 않습니다.

4. 삭제할 수 있는 데이터

요청과 서비스 보유 상태에 따라 다음 항목이 삭제 대상이 될 수 있습니다.

  • 플랫폼 사용자 ID와 사용자 이름
  • 계정 연결 기록
  • 서비스가 보관한 미디어·게시물 메타데이터
  • 댓글 처리 기록
  • 메시지 처리 기록
  • 자동화 실행 기록
  • 전달 및 중복 실행 방지(idempotency) 기록
  • 관련 운영 로그

5. Meta에 보관된 원본 데이터

Instagram, Facebook 또는 Threads에 원본으로 보관된 게시물, 댓글, 메시지, 계정 정보는 Meta가 관리합니다. Dad Builds AI Studio는 자체적으로 관리하는 기록만 삭제할 수 있으며, Meta가 호스팅하는 원본 데이터의 삭제는 해당 Meta 서비스의 설정과 절차를 이용해야 합니다.

6. 처리 안내

요청을 확인한 뒤 삭제 대상과 처리 결과를 이메일로 안내합니다. 보안 사고 대응이나 법적 의무에 필요한 최소 기록은 해당 목적에 필요한 기간 동안 제한적으로 보관될 수 있습니다.
